# Beacon — Knowledge Base

Punto de entrada para cualquier IA o colaborador nuevo.

## Cómo leer esta documentación

- Si eres una IA: empieza por PRODUCT.md, luego GLOSSARY.md
- Si vas a tocar lógica de negocio: lee OPPORTUNITY_LIFECYCLE.md y ATTRIBUTION.md
- Si vas a tocar el producto: lee ACTORS.md y PULSE_CHECKS.md  
- Si quieres entender decisiones pasadas: lee DECISIONS.md

## Documentos

- PRODUCT.md — visión general del producto
- ACTORS.md — quiénes son y qué hacen
- OPPORTUNITY_LIFECYCLE.md — ciclo de vida de una oportunidad
- PULSE_CHECKS.md — el corazón del producto
- ATTRIBUTION.md — sistema de atribución y bono
- DECISIONS.md — decisiones históricas y su por qué
- ROADMAP.md — qué viene después
- GLOSSARY.md — vocabulario del dominio
- STACK.md — tecnología y arquitectura
